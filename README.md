# HouseZone – House Management System

HouseZone is a **web-based platform** designed to simplify **listing, renting, and selling properties**.
The project demonstrates a **modern full-stack architecture** with **Dockerized deployment** and an **automated CI/CD pipeline** on AWS.

---

## 🚀 Features

* User registration and login
* Browse and view property details
* Admin dashboard to add, update, and delete properties
* Image upload and property management

---

## 🧱 Tech Stack

* **Frontend:** React (Vite), CSS
* **Backend:** Node.js, Express
* **Database:** MySQL
* **DevOps:** Docker, Docker Compose, Jenkins
* **Cloud:** AWS EC2, Docker Hub

---

## ▶️ Run the Project

```bash
git clone https://github.com/PiyumiSandunika/Devops_Project.git
cd Devops_Project
docker compose up -d
```
